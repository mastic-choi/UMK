## 1. B1(라바콘)/B2(고정장애물)/B3(방해차량) YOLO 검출조건 — "박스 존재"에서 "최대 박스면적 ≥ 임계값"으로 (완료, 유지)

**요청 배경:** 라이다 AND 조건은 그대로 두고, YOLO 카메라 확인 쪽을 "박스 하나라도 찍히면 검출"이
아니라 "이번 프레임 검출된 박스 중 가장 큰 것의 면적이 일정 값 이상"으로 강화. 이후 그 임계값을
B1/B2/B3 각자 다른 변수로 분리해달라는 추가 요청까지 반영됨(README §5.15, §5.16).

**결과 (완료, 그대로 유지할 것 — 되돌릴 필요 없음):**
- `perception/yolo_cone.py`/`yolo_vehicle.py` — `detect()`는 원래대로 "박스 1개 이상"만 반환(원시값),
  새 `get_latest_max_area()`가 이번 프레임 최대 박스 면적(px², 640 입력 스케일)을 반환. 면적 게이트
  자체는 검출기 내부가 아니라 호출부(track_drive.py)에서 건다 — 같은 콘 검출기를 B1/B2가 공유하는데
  임계값은 다를 수 있어서.
- `config.py` — `YOLO_CONE_MIN_BOX_AREA_PX_B1`/`_B2`, `YOLO_VEHICLE_MIN_BOX_AREA_PX_B3` 신설(전부
  2500.0px²=50x50px 상당, **실차 미검증 placeholder** — 아래 "다음 작업" 참고).
- `track_drive.py` — `perc_lavacon_trigger()`(B1)의 `cone_confirmed_cam`, `perc_obstacle_cut_trigger()`
  (B2/B3)의 `cone_seen`/`vehicle_seen`이 각자의 임계값으로 게이트. `self.cone_max_box_area`/
  `self.vehicle_max_box_area_cut`이 매 틱(해당 phase 활성 중일 때만) 갱신됨.
- `_debug_viz_obstacle_cut()`(`obstacle_cut_debug` 창)에 `[B1]`/`[B2]`/`[B3]` 태그 + 최대 박스면적 +
  임계값을 나란히 보여주는 줄 추가 — 지금 어느 임계값이 적용 중인지 한눈에 보임.

## 2. B1/B2/B3 박스면적 실측 전용 디버그 창 3개 신설 (완료, 실측 후 삭제 예정)

**시행착오 있었음 — 최종 버전만 코드에 남아있음:**
1. 1차 시도: 기존 디버그창 6개를 전부 끄고, Phase 기준 활성/대기 색 구분 + CSV 로거까지 만들었다가
   사용자가 전부 되돌리라고 해서 **완전히 삭제/복구함**(6개 플래그 원상복구, CSV 로거 코드 삭제,
   README에서도 해당 절 삭제).
2. 2차(최종) 시도: 더 단순하게 — 카메라 프레임 + 그 아래 숫자만 보여주는 창 3개, Phase 게이팅 없이
   "노드 켜지면 상시" 요청 반영. 처음엔 `self.cone_max_box_area` 등 FSM 전용 필드를 그대로 읽어서
   실제로는 해당 Phase일 때만 갱신되는 문제가 있었음("상시켜지는게 아닌거같다" 지적) → 세 디버그
   메서드가 `self.img_front`를 직접 detector에 먹여 **FSM phase와 완전히 무관하게 매 틱 강제
   추론**하도록 수정, 실제 주행 로직(FSM이 쓰는 필드)은 전혀 안 건드림.

**현재 코드 상태 (`track_drive.py`):**
- `_debug_viz_box_area_cam_window()` 공용 헬퍼 + `_debug_viz_b1_cone_area()`/`_debug_viz_b2_cone_area()`/
  `_debug_viz_b3_vehicle_area()` 세 메서드.
- `config.py`: `DEBUG_VIZ_B1_CONE_AREA`/`_B2_CONE_AREA`/`_B3_VEHICLE_AREA` 플래그(기본값 전부
  `False`), `DEBUG_WIN_POS_B1/B2/B3_..._AREA` 좌표 (가로로 `(0,0)`/`(340,0)`/`(680,0)`).
- **동시에 여러 개 켜면 랙 걸린다는 실측 피드백 — 반드시 하나씩만 켤 것.**
- 세 값 다 실측 튜닝 끝나면(위 §1의 `YOLO_*_MIN_BOX_AREA_PX_B*` 값 확정) 이 절에서 추가한 코드
  전부(헬퍼+3메서드+`control_loop()` 호출 3줄+config.py 플래그/좌표 6줄) 삭제할 것 — README §5.17에
