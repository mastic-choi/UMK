# `measure_imu_yaw_sign.py` — IMU 요레이트 부호규약 실측 도구

**상태: 2026-08-15 작성, 아직 실차 미실행.** `local_costmap_proposal.md` 선행작업
3순위. README §0.5.5 "IMU 각속도 부호규약이 실차 미검증"이라는 한계를 실제로
확인하기 위한 도구.

## 왜 필요한가

`cb_imu()`(track_drive.py)가 `msg.angular_velocity.z`를 `self.imu_yaw_rate`로
저장하는데, z축 양수(+)가 좌회전인지 우회전인지는 **한 번도 실차에서 확인된 적이
없다**. 지금까지는 `_imu_curvature_px()`(§0.5.5) 등에서 `abs()`로만 써서(부호를
버림) 이 불확실성이 문제가 안 됐지만, `local_costmap_proposal.md`의 로컬
코스트맵(자기위치 추정 — 차가 회전한 만큼 그리드도 같은 방향으로 회전시켜야 함)에는
부호가 그대로 필요해진다.

## 도구가 하는 일

- `/imu`(`sensor_msgs/Imu`)를 구독하면서, 사용자에게 **왼쪽(반시계)/오른쪽(시계)을
  번갈아** 돌리도록 안내한다(기본 4회 = 왼2+오2).
- 각 회차(기본 2.5초)동안 받은 `angular_velocity.z` 샘플의 평균을 낸다.
- 왼쪽 회차들과 오른쪽 회차들의 평균 부호가 **서로 반대로, 그리고 각 방향 안에서는
  일관되게** 나오는지 확인한다 — 우연히 한 번 맞은 게 아니라는 근거를 확보하기 위함.
- 결론("z>0 = 좌회전" 또는 "z>0 = 우회전")과, README/config.py에 그대로 남길 수
  있는 문구를 출력한다.

차량을 실제로 트랙에서 굴릴 필요는 없다 — **IMU 보드(또는 차량 전체)를 손으로 들고
천천히 돌리기만 해도 된다**, IMU 자체의 회전만 재면 되므로.

## 사용법

```bash
# 1) IMU 노드만 띄운다(xycar_imu 등, track_drive 전체 launch 불필요)
# 2) 실행
python3 tools/measure_imu_yaw_sign.py
# 회차 수/회차당 시간을 바꾸고 싶으면
python3 tools/measure_imu_yaw_sign.py --trials 6 --duration 3.0
```

실행하면 회차마다 "왼쪽(반시계)로 돌릴 준비가 되면 Enter"처럼 안내가 뜬다 — Enter를
누른 뒤 안내된 시간 동안 **부드럽게, 급격하지 않게** 계속 같은 방향으로 돌리면 된다.
너무 빨리/급하게 돌리면 노이즈가 커지니 천천히 하는 게 낫다.

## 출력 예시 (가상)

```
=== IMU 요레이트(angular_velocity.z) 부호규약 실측 — 4회 ===

--- 회차 1/4: [왼쪽(반시계)]로 돌릴 준비가 되면 Enter ---
  지금부터 2.5초간 왼쪽(반시계)로 천천히 돌리세요...
  회차 평균 z = +0.842 rad/s (24개 샘플)
...
=== 결과 ===
왼쪽(반시계) 회차 평균들: ['+0.842', '+0.791'] → 전체평균 +0.8165
오른쪽(시계) 회차 평균들: ['-0.803', '-0.775'] → 전체평균 -0.7890

OK — 왼쪽/오른쪽에서 부호가 일관되게 반대로 나왔습니다.
결론: angular_velocity.z 양수(+) = 좌회전(반시계)
```

## 알려진 한계 / 다음 단계

- 손으로 들고 돌리는 회전과 실제 트랙 위에서 조향으로 도는 회전은 물리적으로
  다르다(회전축·진동 등) — 이 도구는 **"부호"만** 확인하는 용도지 요레이트 값
  자체의 정확도/노이즈 특성을 재는 게 아니다.
- 결과를 실제로 코드에 반영할 필요가 생기면(예: 로컬 코스트맵이 부호를 실제로
  쓰기 시작하면) — 지금 `abs()`로만 쓰는 곳들(§0.5.5)은 그대로 둬도 되고, 새로
  부호가 필요한 곳에서만 이 결과(z>0의 의미)를 기준으로 삼을 것.
- 이 확인은 `local_costmap_proposal.md` 선행작업 3순위 — 1순위(라이다 n 확인)·
  2순위(라이다-카메라 오프셋)와 순서 상관없이 독립적으로 먼저 해도 됨.
